# Security and responsible use

This repository documents a vulnerability already coordinated with the vendor, publicly disclosed, and fixed.

- Do not test systems without explicit authorization.
- Use only an isolated local installation containing synthetic data.
- The supplied script refuses non-loopback targets and defaults to dry-run.
- Do not include tokens, credentials, customer data, hostnames or third-party IP addresses in issues.

For new InvoiceShelf vulnerabilities, use the project's private security-reporting channel rather than opening a public issue.
